# 零点杂货铺 · 美术方向 v2

手绘绘本：不透明水彩平涂、干笔边缘与略不均匀的色铅笔轮廓。保留轻微透视偏斜，一张画只有一个视觉重点，道具少于15件；墙、地、右侧30%与底部12%留出低细节区域。全幅场景，不画边框、UI、标签、名字、数字或人物。

这是七个主色族，允许混色、纸纹与抗锯齿形成自然色阶。阴影偏冷，光线柔和漫射；夜版以暖色平涂灯面和灰青阴影表达，不加光晕、光束或金边。紫藤只允许店外和前台窗边各一处；其它场景不用紫藤。

## 每张图的AI痕迹检查

1. 可见笔触；避免光滑塑料、摄影质感。
2. 物件少且一眼能认出；去掉无法说明用途的小零碎。
3. 柜脚、书脊、窗格、门框结构能成立；不用花纹掩盖结构。
4. 不过度对称，不堆叠奇幻雕刻。
5. 无发光晕、光束、镜头光斑、景深模糊、金色花纹。
6. 没有任何字母、汉字、数字、空白牌匾或界面框烘焙在图里。
7. 前景与底图同光线、同笔触；动态物件从原合成扣出，不另画相似贴片。

## 生成基准

STYLE_V2与NEGATIVE逐字沿用HANDBOOK.md对应段落。S02使用手册第一人称旧木柜台、左侧少量瓶书、中央绿布帘门、左窗树影、右侧空墙、柜台盆栽与陶碟。为手册动态清单保留各一处小干花束、风铃、香炉与窗边叶片，控制道具总数；帘幕分左右两幅。所有正式文字由Godot控件绘制。

每张生成最多4次，自审失败保留理由。三候选各按九项清单计分后自主定稿，选定参考的路径与SHA写资源清单。原生尺寸按实际输出记录，运行副本等比裁切/Lanczos到1920×1080，不冒称原生高清。
