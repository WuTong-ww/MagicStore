# A3R 全屏界面壳与遗留问题

**目标**：保留现有 v2 美术与事务流程，把七场景铺满窗口，修复按钮、热区、零客下拉，并落实纸面阅读与咨询布局。

**依据**：`docs/codex/HANDBOOK.md` A3R、原 A3；用户本轮自主迭代规则覆盖试点等审和提问流程。

**方案与决定**：沿用 SceneVisual 配置，新增 cover 投影，保留局部素材 contain 工具。场景为根层，顶栏、底部导航、纸抽屉为覆盖层。小窗口抽屉宽度受窗口限制。原 A3 的外部字体/音频仅采用可核验授权的资源，不能取得时列为未完成，不添加服务或依赖。

**改动文件**：`scripts/ui/{main,shop_front,consultation,ui_kit}.gd`、`scripts/shop/{scene_visual,shop_screen}.gd`、共享抽屉、主题与配色、`data/ui/` 与 `data/shop/visuals.json`、图形/布局测试、`docs/features.md`、资源来源登记。
