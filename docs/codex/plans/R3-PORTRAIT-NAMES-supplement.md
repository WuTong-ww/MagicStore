- 瞳色7种：深棕、棕、琥珀、榛色、绿、灰蓝、蓝。灰阶部件加调色shader；虹膜稍大、有一个小高光点，96px头像仍可见颜色。概率按国籍配置，欧洲蓝/绿/灰较常见，其他以深棕为主，各色概率都大于0。
- 妆容层位于face之上、eyes之下；另有唇色层位于mouth之上。口红：无、裸色、玫瑰、砖红、莓果、珊瑚。腮红：无、淡、中。眼妆：无、淡眼线、大地色眼影。概率按年龄、职业、性格配置；女性默认较高但不限性别，男性可有润唇膏或淡眼线；老年与学生默认较淡。
