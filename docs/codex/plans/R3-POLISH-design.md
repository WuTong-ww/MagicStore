# R3-POLISH 界面设计

沿用 `docs/art/style_v3.md`：旧街小店的木横板、素纸签、蜡封与文楷；场景保持主视觉，界面帮助读人、读牌、读证据。用户已授权无人值守决策（“中途不要问我”），采用下列可逆方案，不再请求设计批准。

配色：旧木 `#62472F`、素纸 `#F3E9D6`、墨色 `#3B2A1E`、鼠尾草 `#82916F`、夜青 `#294548`、蜡红 `#963F35`。颜色和尺寸进入 data 下配置。字体为随包霞鹜文楷，数值使用同系列 Mono；字体字表覆盖只是前检，最终检查实际控件与 Web 渲染。

采用既有场景上的纸面层次：顶栏木横板承载钱袋、油灯、怀表、星星四个无字手绘图标与动态数值；主要操作用蜡封形态，次要操作用系绳纸签；下拉选择呈现为可读卡片。四个手绘状态图标分别生成，简单导航/关闭/耐心等图标用可编辑 SVG，避免字形依赖。继续复用既有 v3 背景与纸张资源。

版式以1920×1080为基准、canvas_items/expand。宽屏保留场景与侧纸；实际显示高度<640px时，工具和推理侧纸变成覆盖全高抽屉。对话≤实际高度45%，人物随之上移；内容使用最小可用尺寸，不靠压扁容器消失按钮。Title背景/灯窗/招牌保持cover对齐，菜单单独进入安全区域，并同步入店显隐和音乐路由。

```
宽屏： [木横板：资源 / 存档 / 设置]
       [场景、客人、牌桌       | 推理纸]
       [简短对话、问题按钮     | 证据栏]
       [纸签导航]

矮屏： [木横板]
       [客人上移、牌桌] [打开工具]
       [≤45%高对话/选项]
       [纸签导航] → 工具打开后覆盖全高
```

选择局部改造而不是重画场景或更换引擎；图片只负责装饰，数字、姓名、状态由控件绘制。说明只精简操作帮助，不裁减固定案件事实、证词和剧情。原NPC保存ID保持；围巾用正确前后层级，帽子采用经实际图像验证的压发/轮廓裁顶，不能靠全透明或禁止所有发型通过检查。

待实际证据解决：滚轮事件在哪一层被消耗（先记录浏览器→Godot→滚动条，不猜filter）；复杂高马尾与帽子的自然接合；新基准下CSS/物理/逻辑尺寸换算。旧尺寸测试重设content_scale_size，会绕过生产stretch，保留其回归作用但不据此宣称短窗口通过。
