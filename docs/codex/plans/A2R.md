# A2R v3 物品图

## 计划（2026-11-22）

目标：以A1R定稿 `assets/generated_scenes/v3_final/style_reference.png` 为风格参考，用docs/art/style_v3.md的V3_ITEM重做九件现有物品（七个catalog商品/原料，另纸纹书签与银叶书夹）。不复用被否决绘本图，不扩展经营内容；扩充留G4。

提示词只描述不透明广告颜料笔触、左上暖光、右侧略冷核心阴影、平底站立与略俯视三分之四角；纯#FF00FF背景，不画文字、用途角标、投影或发光。技术ID lavender实际名月见草，画四瓣浅黄花的月见草，不把它误画成薰衣草。每张实际打开，按AI痕迹与轮廓/光线/底边评分，每件最多4次生成；仍不理想保留最好者并列审阅包。

改动文件：复用本地备份内tools/check_alpha.py、tools/art/item_pipeline.py、scripts/shop/item_visual.gd及其专用测试；恢复必要的UI取图调用。data/art/item_pipeline.json新增/恢复后必须校验，参数按原流程；data/shop/visuals.json物品映射换独立256图与64派生图。物品支持点和底宽存映射供A7读取。assets/ART_ASSET_MANIFEST.json登记实际生成提示词、风格参考与SHA、原生尺寸、去背/缩放处理、透明图和icon路径；清单<500KB，详细receipt仅incoming/ignored审计。tools/regen_art.ps1 -Style v3 -Only items须按item_id/真实对象提示词生成九件，不得生成旧atlas或把{object}原样交给模型；64图只由256图派生。

流程：原图放ignored assets/_incoming/a2r_v3/，保留原始字节；品红色键去背→内缩1px/羽化1px→等比Lanczos入256×256并测bottom_y/底宽→派生64px并加强轮廓→check_alpha。运行图不自带接触阴影，A7统一加。旧atlas按可回退方式归档，全部生产取图入口从统一配置读取；不得用旧快照覆盖A1R场景配置。

验收最多三轮：先必要的alpha/底边/派生和配置回归，再完整scripts/dev/run.ps1 -Test全绿；实际shop_ui和物品对照/256/128/64画面在1280×720与1920×1080截图，root逐张打开检查五项通用标准、64轮廓辨认和底边；原PNG只.tools，最多6张质量85 JPG提交。旧深色64图例改古纸，数字/名字/用途标志由控件绘制。每个通过/不通过及原因在本文件末尾记录。

边界：本任务不先改A7架上算法；旧slot悬浮可以继续列为A7依赖，但物品图、去背、底边和统一配置须先完成。无存档结构变化、无新增依赖或外部付费服务，不改main。完整测试后提交[A2R]并普通Git推送clean，再更新PROGRESS实际hash。
