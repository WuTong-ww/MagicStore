# G6 经营风格报告实施计划

目标：从本局已保存的可追溯行为派生六维娱乐性经营报告；每维显示分数或“观察中”、样本和可点依据。三组明确标为authored的重追问／重商业／均衡假数据得到不同称号。基线df7381f（G5任务888a15d已普通推送），只在codex/round2-clean。

沿superpowers:executing-plans／test-driven-development／verification-before-completion执行。用户已指定无人值守，以下可逆取舍记入最终审阅包，不等待确认。

## 范围与架构

- 新增带严格validator的data/people/style_report.json：六维公式、样本门槛、12称号及优先级、全部简体文案、布局。无eval表达式、模型评分、人格类型字母或NPC人格输入。
- 新纯helper scripts/people/style_report.gd：load_rules、rules_valid、facts_valid、derive；不读墙钟、不写输入／存档，不调用动作。新增source adapter只从成功提交的validated snapshot白名单组装事实与公开证据。
- 旧People.style_report(people)与report投影保留兼容；Bridge新增style_report公开投影供现代UI消费，避免把整份private case/family传入旧People helper。报告只读派生，不增持久字段、不升schema9、不改旧档。
- PeoplePanel接新店长手帐panel，复用古纸主题。依据按钮展开公开详情；有合法visit/action的依据用已有信号进入对应历史接待，Main必须实际消费定位参数，不再全部打开。不能允许任意ID读取隐藏记录；无visit的候客记录在报告内展开，不能编造接待ID。
- 只读、保存失败、同ID replay、重开与切档不增加样本；未披露事件的世界事实和私有NPC人格不影响报告。所有改变状态仍经execute_action_async，报告不另造计数或来源。

## 保守、可逆计分决定

统计窗口取最新最多20个已结束接待，按ended_at／visit_id稳定排序；进行中的接待不计分。具体阈值最终落JSON并由纯库测试独立字面oracle确认。旧字段缺失是coverage缺口，展示观察中，不补造0分。

|维度|只用的记录与计分|门槛／限制|
|---|---|---|
|inquiry 追问与自主表达|每访有效talk均值／4的60分＋free_text占比40分|≥5结束访、≥10条有来源talk；channel不全则观察中。|
|caution 预测前参考|每预测前不同已付费method均值／3，满100|≥3完整预测；quoted/cancelled及预测后付费不计，同分钟需提交顺序。|
|commerce 成交覆盖|有商品成交的结束访占比×100|≥5访；只作推介的有限代理，明确没记录未成交推介，不能伪称推销成功率。|
|relations 主动联系|主动约回访／请介绍数÷(结束访×0.5)，上限100|≥5访、≥2独立有效联系；自动转介绍排除，无机会数据时0联系不记0分。|
|rhythm 接待与候客节奏|0.5×(1−均时／90上限1)＋0.5×(1−真实等待流失率)，×100|≥5访、≥10来源完整已解决到门episode且覆盖窗口；缺基线只显示均时、分观察中。|
|reflection 披露失误后的复盘|已review合法effect／已披露deviated且可review effect×100|≥2真实机会；未披露结果、无失误、条件未满足或无预测都不补0／100。|

至少6结束访、4有分维度才映射称号，否则整体观察中。12标题按JSON稳定优先级：四角摆稳型、相约再逛型、慢火炖汤型、开门细聊型、翻遍牌堆型、多看一页型、柜台热络型、留一扇门型、从容排班型、回头校对型、静看几张型、一页一页型。说明只描述当前记录，不评价现实品德。底部固定“只描述本局可追溯的经营行为，不是 MBTI 或人格测验。”不得输出四字母人格类型。

改回：切回旧report公共键即可恢复旧三类观察；新公式／称号调JSON并升policy_version，不改存档或既有世界结果。当前最小业务缺口（未成交推介日志、完整联系机会）列待确认；本轮不新增全局审计系统。

## 冻结接口（实现前双方核对）

纯库：load_rules(path默认正式JSON)→Dictionary、rules_valid(rules)→bool、facts_valid(facts,rules)→bool、derive(facts,rules)→Dictionary。adapter：collect(state,rules)→受限facts，public_report(state)→纯库输出；具体字段在.tools/g6/report-contract.md冻结后同源实施，不能两套不相容shape。

事实白名单：version/save_id/state_version/as_of_game_minute、window.visit_ids、visits、talks、predictions、paid_services、trades、manual_contacts、arrival_episodes、disclosed_feedback、reviews、coverage、evidence。每事实有稳定id、合法visit或明确无visit、basis_id；完整来源join在可信adapter完成，原始case／world／personality／private family不进入此投影。paid与prediction保留at/order。重复transaction或action镜像去重，冲突不默默凑样本。

现代公开报告：version/policy_version/status/description/title/window、六项dimensions（id,label,status,score或null,sample_count,eligible_count,missing_count,metrics,basis_ids,limitation）、evidence公开索引、notice与ui(copy/layout)。title含id,label,reason,basis_ids或观察中；技术ID仅metadata。不把私有来源路径、NPC人格或未披露结果传UI。
