# A6 动态系统

## 计划（2026-11-22）

目标：Godot4.6.3 Compatibility内置风场、阻尼弹簧、三类动效、少量CPU粒子与真实保存后事件。复用A1R实际六层和A7货架，不重写分层工具，不摇整张C冒充独立物体。最终前台联动因缺合格风铃/花束/帘幕/树叶Li及风铃音预计部分完成，仍完成可用系统并继续第二阶段。

范围/文件：scripts/presentation/wind_field.gd与damped_spring.gd、scene_motion.gd，shaders/scene_sway.gdshader和scene_flow.gdshader，data/ui/motion.json及类型校验，project.godot的WindField autoload；SceneVisual/ShelfView小型动效接点；GameState/PeopleBridge/People事务局部展示事件（不进存档）、Main页面切换与减少动态控件；tests/presentation及集成/性能/MovieMaker脚本，run.ps1强制接入；features/manifest/results/截图与审阅记录。

约定与保守决定：

- 当前S03沙发两层只作static遮挡，S04闭门两层继续static，S07水域两层flow；缺失层具体登记诊断而非blanket skip。不得把hidden door_open整张C或背景赋sway。三个处理器用独立合成fixture验证，合成图只技术测试不冒充正式美术。
- 风场固定种子、显式展示时钟、FastNoiseLite低频和确定阵风表，平均25秒/2–4秒包络，从左向右延迟；室内15%、门风临时60%，天气实际ID rainy增强。所有平衡/幅度/中文文案放motion JSON。
- 弹簧固定子步长、阻尼/限幅，不用RigidBody；5秒阈值以外力结束、相对静态基线计。货架微旋+动态总角度≤3°；selected lift与motion pose统一组合，不让两个tween写同一position。入库12px轻弹，最近两邻0.5°，取出不在待销毁node挂动画。
- flow手动时间、固定原alpha边界、透明采样回退原色，避免水岸/透明边被拉成洞；减少动态时水流极弱，粒子立刻清空。场景不可见/销毁暂停并解绑，不累计隐藏时长突跳。
- 真实到店/离店事件从People状态转换处用事务局部数组返回，保存成功和state_changed后才发净化展示信号；不在candidate塞临时字段、不新增schema。长wait同一次到店又离店必须保留两事件；外等超时不冒充进店。重试/成功replay、读档/切档不重播。咨询页面切换另发只读信号，不等同到店。
- “减少动态”写现有user://presentation.cfg的motion段并保留audio；保存成功后才发布，失败复原控件/内存。独立展示偏好不进入经营存档或推进时钟；中文提示取JSON。
- 粒子全场景合计≤60，使用内置CPU与程序纹理、非叠加发光；缺风铃音不拿click冒充。录像用Godot Movie Maker真实保存动作触发一次到店，600帧/10秒，原AVI放.tools，若现有编码工具可用则压缩运行副本放docs/screenshots/a6并登记；不引入新付费服务/依赖，不把非实时录制当60fps实测。

验收最多三轮：纯风/弹簧解析与确定性、配置负例、实际层分派/固定alpha、A7姿态与真实事务事件、设置往返/音量互保/失败写入、暂停释放/粒子预算；完整run.ps1 -Test必须全绿。实际shop_ui与专项在1280×720/1920×1080截图，root逐张检查通用五项，JPG质量85最多六张；水内部变而岸边不动需像素差分。集显Iris Xe实机1920记录基线/开启/减少动态帧时与动效CPU时间mean/p95/p99/max（CPU测量不冒充GPU成本），判60fps与≤2ms，不达标如实部分完成。10秒前台到店录像与当前水/货架补充证据按实际工具产出，缺前台层的项目明确不通过，不假称视频联动已完成。

待确认/人工（不阻断续跑）：A1R剩余前台Li/cleanplate与风铃音；最终若缺，仅列准确资源组/提示词位置。没有迁移存档、高风险删除或改main，不要求中途批准。完整验收后[A6]提交并普通Git推送clean，再A4→G2→G4→G5→G6。
