纯库接口统一为：

```text
load_config(path: String = "res://data/past_lives/registry.json") -> Dictionary
config_valid(library: Dictionary) -> bool
binding_proposal(context: Dictionary, progress: Dictionary, library: Dictionary) -> Dictionary
service_proposal(context: Dictionary, progress: Dictionary, option_id: String, library: Dictionary) -> Dictionary
interpretation_proposal(context: Dictionary, progress: Dictionary, input: Dictionary, library: Dictionary) -> Dictionary
verification_proposal(context: Dictionary, progress: Dictionary, interpretation_id: String, library: Dictionary) -> Dictionary
progress_valid(state: Dictionary, library: Dictionary) -> bool
public_view(progress: Dictionary, npc_id: String, known_npc_names: Dictionary, library: Dictionary) -> Dictionary
```

提案返回ok/reason及binding_patch、descriptor/cost/result、record或patch；调用者才将patch放入候选并提交。context由事务层构造，含save_id/npc_id/visit_id/action_id/at/cause/is_ordinary/npc_known/known_clue_ids/npc_coins/has_legacy_memory/slot_candidates，客户端不得传truth或cost。实例保存line_id/content_version/definition_sha256、各slot绑定来源、fragments与interpretations独立字典；status为unverified/verified/refuted，verification另列真实证物片段／动作／时刻。

public_view返回version、已见实例标题、三世公共rows、已见片段、公开选择／解读／核实、已披露links与ui(copy/layout)。未知行只有ordinal／通用占位，不带未来identity_id、正文、选择答案或图路径。空memory不返回线标题。CaseView负责按当前NPC取该投影；报价展示实际专价但不提前展示片段正文。细节若必须调整，先在本计划记录裁定并同步双方接口。

公共结构固定：顶层version/available/instance_id/title/rows/fragments/interpretations/options/links/ui；available=false时title与rows为空，不透线名。row有ordinal/title/known/nodes/image_path；未知row不带真实身份ID、image_path为空且仅一个通用unknown node。已知node有identity_id/label/known，可见今生姓名须先有对应verified关联。options只给已取得vision的group_id及option_id/label；interpretations给已记录id、group_id、player_text、status及资料是否足以核实，绝不含私有答案。UI动作可用性仍由现active visit／核心权限控制。

美术路径约定：assets/past_lives/v3/era1_native.png、era2_native.png、era3_native.png及对应era1.png／era2.png／era3.png的1920×1080运行副本；registry以era1/era2/era3 art_key映射运行路径。工具可增加data/art/past_fragment_pipeline.json，参数与文案不写死代码；该JSON由美术工具validator负责。中央manifest仍由root单独合并，工具owner不写中央。
