目标：移除活跃S04_slot木箱格与GridContainer，复用A1R空层板和A2R九件独立图，让底边支点落在层板上。保留原v2全部56文件，旧slot仅复制归档legacy并退出生产使用，不违反v3续跑的保留原图规则。普通Git、无LFS，候选和临时截图不提交。

采用的保守决策（无人值守，不停问）：

- 类别顺序成品→原料→纪念物；同类按首次历史batch数组位置、再item_id稳定排序，旧无批次物品按ID兜底。只在真正数量变化后重排；筛选只筛抽屉，架上保持原位置。无新存档字段，不改schema5/shop1。
- 每种ID占一个展示组，数量1–3画相同数副本，>3画3副本加动态×N纸条。所谓0/1/9/30件按总数量，不为验收造30种内容；溢出用独立窄层板fixture另验。
- 层板、间距16–24、下压2、堆叠10、阴影高12、抬起6统一为原生场景像素；支点来自256图bottom_left/bottom_width/bottom_y，缩放后沿同一native→canvas→cover投影。微旋以底部接触中点，不用PNG画布中心。
- 包装同时检查旋转/堆叠可见边界，避免窄底宽叶互穿；底宽+稳定间距为最小推进，上部形状过宽时加安全间距，记录这个保守解释。随机仅局部item_id种子，不消耗游戏RNG。
- 纸纹使用Godot内置低幅噪声以8%正片叠底覆盖S04艺术层，UI独立；椭圆接触阴影内置渐变纹理，35%正片叠底。没有新增第三方资源或把图片修改当生图。
- 点击架上物品只变显示，抬6px、展开已有右侧抽屉并显示详情。出售/使用沿既有execute_action_async；赠物只读，不擅增玩法。名称仅悬停名签，常驻无名称/普通数量；用途角标仅抽屉。
- 第一次载入/切档仅建立已提交快照基线；入库/取出信号按save_id/state_version去重，失败保存和重放不发；关闭柜门不得显示物品/影子/标签。为A6保留底部旋转节点及信号，不提前实现风场。

- v2不可删与旧slot要归档同时存在 → 保留受保护原文件，legacy复制同SHA且移除活跃引用 → 如需回退切回legacy fixture/配置，不需恢复删除文件。

- 同类物品排序歧义 → 首次历史batch数组index，售空再购仍同历史顺序；filter仅抽屉 → 修改纯布局/category_order即可回退，无迁移。
- 新A7基线不再有slot → register_real_scenes保留shelves/shelf_layout而不强塞旧slot；原legacy契约继续支持 → 29/29注册工具回归，A1R重生不破坏新柜子。
- 纸纹/阴影 → Godot内置程序纹理，配方和参数登记manifest，未增加外部依赖 → 调JSON或换同类Texture可回退，不改库存规则。
- 未新增人工素材；A2R书签/树脂辨识弱点不在A7偷偷改图；A4旧人物是本任务最后全站不通过来源。
