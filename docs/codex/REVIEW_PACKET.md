- 远端LFS预算超限 → 保留本地提交、两任务后按结束条件停止；不付费、不改远端、不绕过LFS → 仓库负责人恢复服务后重推同一分支。

- 小窗口对白内容装不下底部三分之一 → 保证历史、问题、输入完整，按配置缩小并上移头像 → 调整consultation.json的compact_seat与dialogue参数。
- 抽屉挡热区标签 → 被挡标签整枚隐藏，关闭后恢复 → 修改遮挡矩形或标签位置即可。
- 即时充分反馈早于预测窗口结束 → 固定到期的单次事件已有充分证据时评价，未反馈保持pending → 将结局配置改delayed可延后披露。
- 旧档未披露却已有自动评价 → 仅内存改pending/-1，保留世界结果与已披露评价 → 后续评价策略可迁移调整，不强制降写旧schema。
- 历史效果数值与新平衡值可能不同 → 校验来源/阶段/时间/ID与范围，保留已结算金额 → 效果顺序、结局键与阶段需保持稳定，变更须迁移。
- 解锁话题不等于获得线索 → 只开放当前NPC话题，真实交谈才记线索 → 可在JSON移除后续解锁效果，已提交历史保留。
