# 零点杂货铺当前已实现功能

截至 2026 年 11 月 9 日，当前版本是一个可离线运行的 Windows 2D 原型。玩家可以开店、接待林照晚、交谈收集线索、完成一次单牌塔罗结算，并在次日接待她回访。

## 可玩的内容

| 功能 | 当前表现 |
| --- | --- |
| 前台与咨询区 | 前台可开始或继续接待，也可休息、进入下一天和查看往次记录。界面显示营业时间、店长金币、精力和顾客预算。 |
| 固定顾客 | 林照晚是一名旧书修复师。她带来的案例叫《一封没有寄出的邀请》，围绕一张展览邀请和一封没有寄出的回信展开。 |
| 中文交谈 | 支持预设问题和中文自由输入，点击「发送」后才提交。本地对话模拟按关键词识别邀请、回信和旧书修复三个话题，无法识别时会请玩家澄清。 |
| 线索与手记 | 当前案例有两条可发现的线索。同一次接待中，反复询问同一话题不会重复记录线索。来客手记可回看接待日期、对话和已结算的牌名。 |
| 单牌塔罗 | 有星星、隐者、节制三张示例牌，使用统一的占位图，结果显示牌名和解读。确认费用后，双方金币、精力、营业时间和结果一并保存，再显示牌面。同一次接待只收费一次，退出重进仍可查看原结果。 |
| 营业与回访 | 营业时间为 09:00–22:00。休息可恢复精力，结束接待后可打烊。次日 09:00 精力回满，林照晚可以开始一轮新的接待。 |
| 多存档与恢复 | 可新建独立存档或继续已有存档。成功操作会自动保存，未结束的接待可从上次状态继续。主档损坏时可手动恢复可用备份，进度会回到该备份对应的时间点。 |

开局店长有 **40 金币、100 精力**，顾客预算为 **60 金币**。每次成功交谈推进 5 分钟，休息推进 60 分钟并恢复 30 精力。塔罗收费 20 金币，消耗 25 精力和 30 分钟。顾客预算跨日保留，当前案例最多完成三次付费占卜。

## 如何体验

1. 按运行说明安装固定版本的 Godot，然后双击 `start-game.cmd`。使用 Windows 试玩包时，解压后运行 `StartGame.cmd`。[运行说明](../README.md)
2. 在存档簿新建店铺，从前台进入咨询区。可以点击问题按钮，也可以输入「为什么还没回信？」后点击「发送」。
3. 确认塔罗费用，查看牌面与资源变化。返回前台后再进入咨询区，或退出游戏后读取同一存档，均可继续原接待。
4. 结束接待，在来客手记中查看记录。打烊后进入下一天，即可体验回访。

## 实现与验收范围

项目使用 Godot 4.6.3、GDScript 和 Compatibility 渲染模式，已包含源码、中文字体、Windows 导出配置、启动脚本和自动化测试。已通过 168 项核心、对话接口和界面自动检查，以及两进程重启恢复检查。Windows 导出包已在本机验证启动、新建存档和付费占卜。真实输入法选词与其他电脑兼容性仍待补验。[验收记录](verification.md)

当前对话使用本地模拟，生成式 AI、随机客流、人物关系和正式预测反馈尚未接入。储物柜、工坊、原料商店、采集、物品支付及技能成长属于后续范围。[原始游戏构想](游戏介绍.md)
