## 试玩路线

1. 新建店铺，从前台接待正在排队的来客。可在「候客与档案」查看来意、推荐来源，协商预约或等待。离店的客人不会继续出现在前台选择中。
2. 与照晚交谈、做一次塔罗。在工坊为缺货的药水或晶石登记需求；结束接待后研究配方。在原料商店购买、领取合条件的赠料，或去河畔小径或林缘草地采集，再回工坊制作。
3. 储物柜可出售原料、把成品卖给正在接待的来客，或记录使用。药水也可由店长自用。对话后使用澄心晶，可点开新的温和追问。定心香必须在邀请案发生前、关联本次交易使用。
4. 邀请案、旧物案与原创新人物案例按各自数据规则提交预测和建议。结果到期后由 A 根据人物条件安排反馈；可能延期或不回来。未反馈时预测保持待验证，充分证据才显示实际结果，部分证据只记录顾客感受。储物柜可查看口碑、经验、复盘与客流加成。

主要文字为 18–26 像素，次级记录为 16 像素；长内容位于滚动区域。技术编号默认隐藏，可在储物柜勾选「显示记录编号」。

## AI 接口设置

首页右上角的「设置」提供 URL、模型名称、API Key 三个输入框，支持 HTTP/HTTPS 的域名、公网或内网 IP 及端口。URL 可填写根地址、以 `/v1` 结尾的地址或完整 Chat Completions 地址；离开输入框及应用时会检查格式并自动补全，结果直接显示在输入框内，格式错误保留可编辑。输入框默认留空，API Key 隐藏显示；设置仅在本次进程有效，不进入存档或交付包。点「使用本地对话」可切回离线模式。

游戏中途只改同一URL的模型时，留空密钥可沿用本次已填写的密钥；换URL则必须重新填写。修改设置会取消旧请求，不消耗游戏时间，也不改当前接待。DeepSeek、GLM 5.3、GLM Flash、Qwen的实际切换、等待时间及已知上游波动见[接口切换验证](api-model-switch.md)。

仍可通过进程环境变量 MAGIC_GATEWAY_URL、MAGIC_GATEWAY_TOKEN 使用 A 的本机网关；MAGIC_GATEWAY_TIMEOUT 控制请求超时。该模式的令牌是网关口令。两种在线模式现在都实际生成顾客对白。自由输入先选话题，再向生成器提供这次获准谈及的材料；按钮省去话题识别。生成 prompt 包括经过筛选的人物身份与语气、本次交谈、往次来访和双方共同记忆。隐藏世界事实、未披露事件结果、其他人的私事及未选择话题的答案不会发给生成器。

模型先写出对白并引用资料，再由另一次模型请求检查冲突、无来源断言和引用是否对应实际披露。程序另查字段、引用范围、保护词、日期、数值与内部标识。通过后保留模型原句并保存；未通过、超时或审核服务不可用时使用手写对白。普通寒暄不发放话题线索。候选对白在审核完成前不显示，也不改变资源。总请求期限为 45 秒，取消与迟到回复仍受原有保护。

对白同时返回2–3条可继续问的自然问题，审核通过后更新咨询区按钮。问题只选当前可用的话题，不提前透露隐藏答案；点击发送原问题，换来客不会串用旧按钮。问题随对白保存，缺失或无效时由可用的本地问题补齐，不增加额外模型请求。短暂服务故障可在原45秒期限内重试一次，认证、格式或审核失败不重试。详细契约见[动态后续问题](followup-questions.md)。

完整生成与审核 prompt 在 scripts/providers/dialogue_policy.gd，网关对应版本在 server/ai/gateway.py。人物陈述、玩家说法、预测和已披露事实在资料中分别标注；模型无权修改世界事实、人物身份、金币、物品或时钟。语义审核本身仍可能误判，规则测试通过不代表对任意模型输出的绝对保证。

HTTP 已用实际本机网络和模拟服务测试。此前用 PJLab 的 deepseek-v4.1-flash 完成林照晚84次真实交谈、12次接待；少推演提示后的14次平均3.14秒，包含独立审核与保护性回退，具体见[此前实测](live-dialogue-evaluation.md)。本轮新增原创新人物生成与实测另见[人物生成说明](people-generation.md)，不要把固定人物旧测量当成所有新人物的速度或质量保证。旧本地来客仍可复用 B 的旧物案例；联网后台新生成的来客使用各自已审核的专属案例。四模型已验证中途切换及少量实际对白；原创新人物完整跨次质量复测仍只覆盖DeepSeek。
