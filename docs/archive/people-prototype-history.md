# 早期原型与人物独立演示历史

本页解释已撤除入口和旧文档背景，不是当前运行指南。主游戏统一从 `start-game.cmd` / `project.godot` 启动；现状见[功能清单](../features.md)，接口见[公共契约](../contracts.md)，验证边界见[验收记录](../verification.md)。

## 原型阶段

- 2026-11-06 的基础原型围绕林照晚、邀请案、本地关键词对话和基础结算验证，曾使用 v1 单人物结构、三张占位牌和两处场景示例。同期记录包括核心57项、provider48项、headless界面63项、图形界面68项及跨进程恢复；只对应当时快照，不是当前测试总数。
- 2026-11-15 的独立人物模块曾提供临时内存中的来客、候客、预约和外观交互，入口为 `start-people-demo.cmd`，调用 `scripts/dev/run-people-demo.ps1` 和 `scenes/people/people_demo.tscn`。它不读写正式存档，不能用来证明当时已完成公共状态整合。
- 当时交接记录包含200个固定种子的400次普通来客和9次参考人物触发，以及规则、反馈、两进程恢复和面板/独立演示动作验证。这是历史数据，不要求当前正式配置继续保留参考人物样例。

早期另验证过本地 JSON 主档/备份恢复、两进程续档、Windows 导出和实际启动。它们针对当时的原型结构和环境，不能替代当前版本的存档兼容、主游戏整合或导出验证。

## 后续整合与撤除

此后人物、排程、记忆、实际候客、经营、问卜、公共存档、HTTP生成与审核均已接入主游戏；模型人物也有专属案例、正式来访、介绍和回访。旧文档的“HTTP未来接入”“人物与公共状态尚未整合”等待办已经过期。

本次撤除独立人物演示入口、场景和专用测试，将入口、测试清单、包体必需项及当前文档统一到主工程。人物面板及主游戏仍使用的规则、术式、素材和隔离测试继续保留。

旧卡牌数据改放 `data/compatibility/legacy_cards.json`，内容加载器将其补入兼容目录，旧存档的卡牌 ID 和已保存牌面仍可读取；当前正式塔罗的78张牌机制没有被删除。

历史 `.tools` 报告、构建证据和正式存档不属于本次演示清理目标。历史记录不改写成新版本结果，也不复制成多份“最终报告”。
