# 游戏介绍

## 一 日常项目介绍

我正在制作一款暂名《零点杂货铺》的神秘学小店经营游戏，融合小店经营、店长成长、AI角色互动和连续剧情。玩家扮演店长，接待来问卜或购物的顾客，通过交谈、提问和占卜了解问题、作出推断与建议，也可以研究制作帮助顾客的商品。希望玩家能感受到：自己在经营小店的同时，也在逐渐认识并影响一群有生活、有关系的人。

顾客保留共同剧情中的固定NPC；在随机来客中，大多数是原创普通NPC，少量是有明确影视或文学背景参考的稀有特殊NPC。这些特殊人物可借鉴国内外影视剧或小说角色的性格、身世、核心矛盾及家族关系，使用谐音名、别名与行为彩蛋，让熟悉原作的玩家产生辨认和联想的乐趣。例如参考《暮光之城》系列或《红楼梦》的人物家族，设计适合本游戏的新处境、问卜需求和互动分支。这种参考适用于顾客今生的完整设定，也可以与前世故事结合。

普通随机NPC占客源主体，特殊NPC的生成比例和初次登场频率较低，具体权重可配置。特殊家族先建立成员与关系，再分批登场，避免一次出现整个家族挤占普通客流。首次遇见后，人物身份、外貌、家族、关系和经历持续保存，后续回访不重新抽身份或家族。

所有人物都有身份、职业、生日、星座、MBTI、性格、经历与偏好。先建立NPC之间的关系网和初始亲密度；玩家的服务与建议可能改变顾客和被问之人的亲密度。剧情采用手写内容与AI生成、有限自主发展相结合的方式。熟客记住之前的接待，玩家可以回看经历，并在熟悉后提出更贴切的问题。提问既支持选项，也支持能产生实际效果的自由输入。

每次正式占卜，顾客需要支付报酬，可以是钱或物品。玩家的推断可能出错，甚至误导后续建议；顾客会在相关事件发生后，根据性格和行程决定是否回来反馈。失误可能降低信任，但也能带来能力成长；成功可能带来回头客、礼物、口碑和转介绍，且能看到推荐人。服务积累还可形成有行为依据、娱乐性的店长风格报告。

店长开局只会塔罗，后续花钱、精力和时间学习雷诺曼、梅花易数、易经、小六壬，以及消耗更高的现代占星、八字、紫微盘等（其中这些更高阶的技能可以看到更宏观的信息，比如顾客的流年命运等等）。还可学习前世推断技法，发现顾客跨越前世今生的因缘。精力不足可以花时间休息或进入下一天。每天客流不固定，可能零客或爆单，受口碑、经验和推荐影响；顾客排队时有与性格、处境有关的耐心，等太久可能离开并影响后续客源。

商品随经营逐步扩充：顾客需求带来灵感，接待结束后再研究配方、取得原料和制作。即使本次没有合适商品或没有成交，也能推动学习。原料可采购、由顾客赠送或外出采集，也能直接出售。商品有药水、水晶、香氛等形态，并按物理、心理、环境等作用分类，能在游戏内提供属性或事件帮助。

美术是重要体验，要有统一审美、角色辨识度和场景生活细节。主要画面包括店外、带信息与状态栏的第一人称前台、有沙发的一对一神秘咨询区、可打开的储物柜，以及制作、原料商店和采集页面。玩家可用组合部件捏脸，随机顾客组合外观，固定NPC保留设定。团队先设计部分商品与原料视觉样例，再用AI按统一风格扩展。

以上是完整项目背景。我们是四人团队，先争取一个月左右的试玩版。请结合我接下来提供的具体任务、已有工程和当前进度开展工作；本轮只处理指定范围，并保持人物、关系、库存、时间、精力与剧情记录的一致性。

## 二 完整项目背景

请以“理解游戏目标并协作完成具体任务”的方式帮助我。项目暂名《零点杂货铺》，是一款以神秘学小店为背景的经营与AI互动叙事游戏。玩家作为店长，通过问卜、沟通、商品服务与长期来往，逐渐影响顾客的生活和人际关系，同时发展自己的能力与店铺。

【核心体验】

我希望顾客是有生活、有秘密、有社会关系、会记住玩家并继续发展的人。玩家需要理解需求、判断信息、作出可能正确也可能错误的建议，并看到后果。经营、技能成长、人物故事和商品研发应互相推动。

一次典型过程是：顾客带着问题来店，双方约定报酬；玩家交谈、选择问题或自由输入，再使用已学工具收集线索，作出预测与建议；顾客可以另行购买商品，也可以只问卜。事件发生后，对方可能回来反馈，带来信任变化、学习机会、礼物、口碑或新客。没有适合商品的需求，也可能成为接待结束后的研发灵感。

【问卜与反馈】

1. 顾客可单纯问卜、单纯购物，或两者结合。每次正式占卜都有报酬，支持钱或物品；问卜报酬、商品交易和额外赠礼分别记录。
2. 玩家通过沟通、提问与技能推断信息。选项和自由输入都应能引发可追踪的效果，例如新线索、关系变化、剧情分支或需求。
3. 推断不保证准确。区分世界实际情况、顾客陈述和工具线索、玩家的假设与对外预测。错误理解可能误导建议，建议与商品使用也可能影响后续事件。
4. 顾客反馈时间关联所问事件的发生时间，再结合性格、行程与关系决定延迟、回访或不反馈；不固定为隔天必来。尚未反馈不自动判成预测失败。
5. 失误可能损失信任，同时带来复盘和某些能力成长。成功可能带来熟客、转介绍、赠礼、口碑与一段时间内的客流增加，具体结果按人物和事件条件发生。

【人物与关系】

1. 有每个玩家都能遇到的固定NPC，也有随机生成的顾客。随机来客以原创普通顾客为主体，少量加入有明确影视或文学背景参考的特殊NPC或家族。固定人物基础设定一致，各存档的实际经历独立发展；特殊人物是否出现可受低概率与条件触发影响。
2. 人物档案包含MBTI、身份、职业、生日、星座、性格、偏好、出身与经历，并通过表达习惯、行为和故事体现。不同人物对同类建议和剧情走向有不同偏好。
3. 先建立NPC之间的关系网和初始亲密度，再生成与之相符的问题和经历。顾客可能来问另一个人的事；解决方式与事件后果可能改变顾客和被问之人的亲密度。
4. 店长与顾客的熟悉度、信任度，以及NPC彼此的亲密度，是不同关系指标，分别记录。
5. 顾客能多次光顾。保留身份、外貌、历次来店、预测、反馈和已知经历。熟悉后开放更懂对方的追问，但仍保留各自的信息边界。
6. 手写关键人物与故事，结合AI生成顾客、反应与后续事件。普通顾客从原创随机模板生成，作品参考人物从策划明确指定的角色或家族模板生成，二者都尊重既有事实；后续互动可以发展新剧情，不随对话重置人物，不要ooc，参考的人物性格越还原越好。
7. 长期观察玩家实际行为，形成有解释依据的娱乐性经营风格报告。若进一步设计人格量表，需要说明依据和验证程度，不能直接宣称已科学测出真实MBTI。

【作品参考特殊NPC与稀有性】

1. 影视或小说参考用于生成可辨认的特殊人物与人物群体：包括性格、身世、家庭背景、核心矛盾、成员关系和表达习惯。目标是让玩家通过互动发现熟悉的角色原型，获得彩蛋与联想的娱乐体验。
2. 可以从国内外影视剧或小说中挑选明确的参考作品。例如为《暮光之城》系列的人物家族、《红楼梦》中的人物家族建立参考模板，再为他们安排符合本游戏世界的新身份表达、当下问题、占卜需求和分支事件。具体选哪些作品由策划决定，示例不代表已经确认整套角色内容。
3. 命名可以使用谐音名、别名、称谓或其他有设计的彩蛋；辨识点还应来自人物性格和关系背景。角色、家族与新剧情需要融入同一游戏世界。
4. 普通原创随机NPC占主要数量和出场机会，作品参考NPC占较低比例。首次生成权重、特殊家族触发频率、家族成员数量与同一时间段出场上限分开配置；本需求暂不指定固定百分比。家族内容的抽取与成员个体的比例要分别统计，避免抽中一个家族就大量增加特殊人物。
5. 家族先建立一个完整且自洽的模板，包括成员、辈分、亲属或其他关键关系、共同背景与初始亲密度。进入某个存档后建立该家族的持久实例，再逐人或分批登场；同一家族的不同成员读取同一关系网络，不各自重造背景。
6. 稀有性主要控制首次遇见和新特殊人物的引入。已经遇见的特殊NPC可以按经历、信任与剧情正常回访；回访沿用原npc_id、家族与记忆。普通顾客同样在首次生成后拥有稳定身份。特殊人物的回访频率另配，整体客流持续以普通顾客为主体。
7. 分开记录角色来源与出场方式：来源可以是原创或作品参考；出场方式可以是固定剧情、随机初遇、条件解锁或回访。不要因为特殊人物来自固定参考模板，就让所有玩家必定遇到；也不要因为普通人物随机生成，就让他每次回店都换身份。
8. 内容配置至少记录来源作品、参考人物或家族、模板ID、改写后的姓名与背景、成员关系、初始亲密度、稀有级别、出场条件与存档实例。允许玩家改变关系、选择与后续发展，不要求新剧情重演原作结局。

【店长成长与前世今生】

1. 开局只会塔罗。后续投入金币、精力和学习时间，逐步学会雷诺曼、梅花易数、易经、小六壬，以及消耗更高的现代占星、八字、紫微斗数与紫微盘。不同工具应带来有区别的使用方式、线索或服务选择。
2. 玩家有精力条。服务、学习及其他经营行动按规则消耗；不足时可以花游戏时间休息，或结束当天进入下一天。
3. 在游戏的玄幻世界设定中，玩家还可学习推断前世的技法，逐步发现顾客前世片段，以及跨越多世的关系与纠葛。部分问题关联前世，部分仍来自今生处境。
4. 前世线索、身份与关系要形成持续的故事记录；看到片段与正确理解片段是不同的事。普通、固定与作品参考NPC都可以按剧情条件关联前世。影视小说参考适用于人物今生的性格、背景和家族，也可与《鬼怪》等作品启发的跨世情感主题结合。

【客流与经营时间】

1. 每天顾客数量不固定，允许零客日，也允许集中到店、超出接待能力的爆单。
2. 来客受店铺口碑、经营经验、人物目标、回访与朋友推荐等共同影响；顾客卡能看到推荐人，并保存推荐来源。
3. 来不及接待时可以排队或协商预约。顾客有耐心，受性格、紧急程度、行程与关系影响；等待太久可能离开，降低回访意愿，甚至流失客源。
4. 学习、制作、采集、服务和休息使用同一个游戏时间体系，耗时行动会影响等待者。现实中阅读、输入或等待模型不额外扣顾客耐心。

【商品与原料】

1. 开局商品较少，靠经营和顾客灵感逐渐丰富。遇到暂时没有合适商品的需求，可以先服务或登记，结束这次接待后再学习研究制作。
2. 配方由我们配置，允许按原料组合制作。药水、水晶、香氛等是形态类别；物理加成、心理加成、环境加成等是用途类别，两套分类可以交叉。
3. 商品可在游戏中提升属性、改变事件条件或提供新的解决问题方式；效果应有可执行的规则，购买、使用和反馈能关联起来。
4. 普通原料从商店采购，隐藏或高级原料可以由顾客赠送，自然原料可外出采集。原料也能直接卖，制作与出售读取同一库存。
5. 团队原创一部分商品与原料形象作为视觉样例，再让AI参考这些样例批量扩展，保持造型语言、材质、色彩和画面规格一致。

【画面与场景】

美术是项目的重要组成部分。画面需要统一而有辨识度的审美、清晰构图、细腻材质和有人生活的空间细节，避免泛用、重复、缺少设计依据的AI视觉感。

主要场景包括：

①店面外观；

②第一人称前台，包含信息栏与状态栏；

③顾客一对一服务区，有沙发等家具，布置私密、神秘；

④储物柜入口及打开后的画面，展示商品与原材料；

⑤商品制作页面；

⑥原材料商店页面；

⑦外出采集页面。

需要店面、人物和商品形象。玩家可捏脸，顾客外观从同一套兼容部件组合，固定NPC保留预设。可参考《女帝的日常》所启发的组合头像方向，具体素材库、来源与使用方式另行确认，不预先视为已确定资源。
